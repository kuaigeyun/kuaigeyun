# 快格云制造 功能清单

面向离散制造企业的轻量 MES：以统一需求模型贯通「销售 → 研发 → 计划 → 执行 → 质量 → 设备 → 仓储」，支持按插件渐进上线。

**一句话价值**：用一套可渐进实施的制造系统，替代 Excel + 纸单 + 多系统割裂流程。

**适合谁**

- 10–200 人离散制造企业
- 多品种小批量，按单 / 按库混合生产
- 需要先跑通核心执行，再逐步扩展全流程协同

**交付形态**：PC Web + 后端 API；移动 App / H5 / 企微钉钉飞书 / 触屏工位 / TV 看板可按项目组合交付。

## 二、快制造（核心 MES）

### 销售管理

销售中心、客户池、报价、跟进、订单评审、框架合同、销售预测、销售订单 / 变更、发货通知、销售退货；销售报表（订单 / 出库 / 退货明细、未交、存货 / 客户汇总、业绩、排行、对账等）。

### 交付项目

交付中心、交付项目、流程模板、节点汇报、流程排单、问题跟踪及交付报表。

### 计划管理

计划中心、需求计划、MRP 需求计算、需求变更、可视排产 APS、滚动计划；计划报表（明细、短缺预警、达成率）。

### 采购管理

采购中心、申请、询价、订单 / 变更、到货预警、收货通知、采购退货；采购跟踪 / 执行 / 供应商交货 / 对账报表。

### 生产执行

制造中心、工单、报工、返工工单 / 策划、委外、装箱绑定、标签工位、生产日报 / 模板、报工统计；异常（缺料 / 延期 / 质量）闭环；生产类报表与预警。

### 质量管理

质检中心；IQC / FAI / IPQC / FQC / OQC；不良处理、SPC、8D、客诉、供应商评价、追溯、质检方案；ISO 条款 / 体系文件 / 内审 / 管理评审；质量统计报表。

### 设备运维

运维看板；设备台账与点检 / 巡检 / 保养方案；点检、巡检、报修维修、保养计划与执行、备件领用、调拨 / 报废 / 检定 / 换线 / 状态；模具与工装全套台账 + 领还维保校准 + 报表；设备 KPI（含 MTTR / MTBF）。

### 仓储管理

仓储看板、物料中心；入 / 出库（含其他入出、借还料、代工来料、送货单）；盘点、调拨、组装、拆卸；即时 / 批次库存、线边仓、倒冲、补货建议、库存预警、条码映射；收发存与呆滞 / FIFO / 盘点差异等报表。

### 物流管理

发货、物流跟踪、运费、车辆、驾驶员、承运商。

### 售后服务

售后工单、装机档案、安装执行、维修、派工、备件申领、服务结算、客户回访。

### 绩效管理

假期、班次、排班、工作日历、技能、工时单价、KPI 定义与员工绩效、绩效汇总及效率 / 计件报表。

## 十二、实施分期建议

1. **一期（跑通）**：主数据 + 销售 / 计划 / 采购 / 工单报工 + 基础仓储 + 平台权限审批  
2. **二期（闭环）**：质量全检 + 设备模具工装 + 进阶仓储物流 + 轻财务往来  
3. **三期（经营）**：绩效售后、快研发、总账成本、快报表 / 数采 / AI（按预算选配）  
4. **行业包**：按客户产线选装电子 / 轮毂等，避免首期摊大
